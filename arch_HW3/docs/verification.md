# Проверка от 03.11.2026

Выполнено на Docker Desktop, отдельном Compose-проекте arch-hw3-test:

```bash
sh scripts/test.sh
```

Результаты:

- **59 тестов прошли**: unit-проверки interceptor и интеграционные проверки настоящих REST/gRPC/PostgreSQL/Redis.
- E2E REST → Booking → gRPC Flight → две PostgreSQL завершился PASS; реальные SELECT показали резервирование, снимок цены и возврат мест.
- Все 7 Flight RPC проверены без ключа и с неверным ключом: UNAUTHENTICATED.
- Два конкурентных запроса последнего места: один успех, один RESOURCE_EXHAUSTED; остаток неотрицательный.
- Повторы одного booking_id создают одну резервацию. Потерянный после commit ответ повторяется без двойного уменьшения мест.
- Реальный gRPC deadline вызвал retry; INVALID_ARGUMENT/NOT_FOUND/RESOURCE_EXHAUSTED не повторяются.
- Ошибка после ReserveSeats перед локальным booking commit компенсирует резерв, CONFIRMED-записи нет.
- Сохранённые незавершённые CREATING и CANCELLING восстановлены worker. В тесте воспроизводится долговечное состояние после сбоя, а не принудительное убийство Booking-процесса.
- Инвалидация и TTL проверены; подставленная старая кеш-запись отвергнута по epoch.
- Flight-контейнер действительно остановлен: после пяти логических сбоев breaker OPEN, следующий HTTP 503 CIRCUIT_OPEN получен примерно за 0.003 секунды. После запуска Flight: HALF_OPEN → CLOSED и 200.
- Текущий Redis master действительно остановлен; Sentinel переключил redis-master → redis-replica-2. Приложение записало TTL-кеш в новый master без изменения конфигурации клиента.
- Все три Redis data-node остановлены; чтение рейса через REST продолжило работать через PostgreSQL.
- Временные тестовые контейнеры, volumes и сеть удалены скриптом. Рабочие данные не очищались.

Это воспроизводимые проверки конкретной реализации, а не измерение производительности или гарантия мгновенной атомарности двух БД при бесконечном сетевом разделении. Границы компенсации описаны в decisions.md. GitHub Actions настроен на тот же сценарий; удалённый CI запустится после загрузки проекта в GitHub.
